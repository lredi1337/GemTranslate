# «Переводчик» — ярлык для Android

Маленькое приложение с иконкой переводчика. По нажатию открывает чат с Canvas переводчика в Gemini
и само нажимает «Открыть» и «Развернуть». Переводчик по-прежнему работает внутри Gemini, на вашей подписке.

## Установка

1. Скачайте `Translator.apk` из раздела **Releases** этого репозитория (последняя сборка сверху).
2. Откройте файл на телефоне и разрешите установку из этого источника, если система спросит.

## Настройка (один раз)

При первом запуске откроется экран настройки. Потом в него можно попасть долгим нажатием на иконку → «Настройки».

1. **Ссылка на чат.** Откройте чат с переводчиком на gemini.google.com в браузере и скопируйте адрес страницы
   (вида `https://gemini.google.com/app/…`). Вставьте его кнопкой «Вставить из буфера».
2. **Автонажатие.** Нажмите «Открыть „Специальные возможности“» → «Установленные приложения» →
   «Переводчик: автооткрытие» → включить.
   - Если переключатель серый («Запрещённые настройки»): «Открыть сведения о приложении» → ⋮ вверху справа →
     «Разрешить запрещённые настройки», затем снова включите службу.
3. «Сохранить и открыть переводчик».

## Что делает служба и что она видит

- Видит только приложения Gemini и Google (внутри которого Gemini иногда работает) — больше ничего.
- Работает 20 секунд после нажатия на иконку: находит «Открыть» у Canvas, затем «Развернуть». Когда вы
  открываете Gemini сами, она ничего не нажимает.
- Если Gemini переименует кнопки, в настройках можно вписать новые подписи. Там же есть «Последний запуск»:
  что получилось и какие кнопки служба видела на экране — по этому списку легко найти новую подпись.

## Обновления

Новая сборка появляется в Releases автоматически. Ключ подписи по умолчанию создаётся заново для каждой сборки,
поэтому перед установкой новой версии старую нужно удалить (ссылку придётся вставить заново).
Чтобы обновления ставились поверх, добавьте в Settings → Secrets and variables → Actions репозитория:
`LAUNCHER_KEYSTORE_B64` (файл ключа .jks в base64) и `LAUNCHER_STORE_PASSWORD` (пароль ключа, алиас `launcher`).

## Служба только на время запуска (для банков и платёжных приложений)

Некоторые приложения отказываются работать, пока включена сторонняя служба «Специальных возможностей».
Если один раз выдать ярлыку разрешение через ADB, он будет сам включать службу при нажатии на иконку
и выключать её, как только переводчик открылся:

1. На телефоне: «Параметры разработчика» → включить «Отладка по USB». Подключить телефон к компьютеру, разрешить отладку.
2. На компьютере (нужны Android platform-tools):

   ```
   adb shell pm grant app.aitranslator.launcher android.permission.WRITE_SECURE_SETTINGS
   ```

3. Выключить службу «Переводчик: автооткрытие» в «Специальных возможностях» — дальше она включается сама.

Разрешение действует, пока приложение установлено. После переустановки (удаление → установка новой версии) команду нужно выполнить снова.
