# «Заказы» — блокнот официанта для Android

Две вкладки с общей схемой зала:
- **Заказы** — заказы по гостям, обязательные опции блюд, стоп-лист и отметка «вбито в POS»;
- **Сервировка** — чего не хватает на столах и что взять со станции.

Работает без интернета, всё хранится на телефоне.

## Установка

Скачайте `Zakazy.apk` из последнего релиза **«Заказы — сборка N»** в разделе Releases и установите.
Новые сборки ставятся поверх старой, заказы и стоп-лист сохраняются.

## Как пользоваться

- **Стол:** нажать на стол → выбрать число гостей → добавлять блюда. Блюдо уходит выбранному гостю.
- **Позиция в заказе:** нажать на неё — перенести другому гостю, изменить примечание или удалить.
- **Стоп-лист:** «🚫 Стоп» → «📋 Вставить» (текст из рабочего чата как есть) → «Загрузить стоп-лист».
  Ниже появится «Как я понял»: что поставлено на стоп по каждой строке и что не найдено в меню.
- **Своя позиция** (нет в меню приложения, например «Хлеб: белый / чёрный»): раздел «★ Свои» → «+ Добавить свою позицию»,
  или «Добавить в меню» прямо из поиска, если ничего не найдено. Варианты выбора — по желанию; ✎ — изменить или удалить.
- **Одна позиция на стоп:** зажать её в меню. Так же она возвращается.
- **Сервировка:** вкладка внизу → нажать на стол → отметить, чего нет. «Собрать со станции» — что взять
  («Что взять») и куда отнести («Куда нести»). После «Закрыть стол» в заказах окно сервировки открывается само.
- **Схема зала:** ⚙️ вверху → двигать столы, «+ Стол», нажать на стол — номер или удаление.
- **«Назад»** закрывает окна и экран стола.

## Для разработчиков

```
waiter/web/index.html   — приложение целиком (HTML + JS), здесь все правки
waiter/tools/build.js   — встраивает стили Tailwind → android/app/src/main/assets/index.html
waiter/android/         — WebView-обёртка (MainActivity): буфер обмена, вибрация, копия данных, «Назад»
```

После правок: `cd waiter/tools && npm install && npm run build`. APK собирает GitHub Actions
(`.github/workflows/waiter-apk.yml`) с тем же ключом подписи, что и ярлык переводчика.
Меню — в `MENU_CATEGORIES`, предметы сервировки — в `SERVE_ITEMS`, варианты опций — в `MODIFIER_CONFIGS`, схема столов — в `DEFAULT_TABLES`.
